模型广场上最近流传一种说法：GPT 是「官方 0.09 折」，Claude 是「官方 0.39 折」。先把话说清楚——这**不是** OpenAI 或 Anthropic 的官方折扣活动，也不是官方 API、官方 ChatGPT / Claude 订阅在打折。它指的是第三方接口聚合站 momoAPIPro（[tryallapi.com](https://tryallapi.com/)）上某些**分组价**，对照官方 API 标价之后的倍数。

按中文习惯，「0.09 折」会被理解成标价的 0.9%，和实际差额差了一个数量级。更准确的说法要按今天对过的数字来写：在 **2026 年 11 月 20 日（Asia/Shanghai，UTC+8）** 的公开目录里，`gpt-6.2-astra` / `gpt-6.2-sol` 最便宜的 **Codex-Gpt-1** 分组，输入价约为官方 Standard 短上下文标价的 **0.08 倍**（准确计算是 8.09%，大约 0.8 折）；`claude-fable-5-2` 最便宜的 **Claude-Code-1** 分组，约为官方标价的 **0.39 倍**（准确计算是 38.82%，大约 3.9 折）。这两个低价只在对应分组被选中、并且当天仍然开放时才可能适用，不能理解成「只要调用这个模型 ID，就一定按这个倍数扣费」。

本文按当天模型广场截图、公开定价接口，以及官方定价页的复核来写。tryallapi.com / momoAPIPro 是**第三方 API 聚合站**，不是 OpenAI、不是 Anthropic，也不是官方 API。文中的 Codex-Gpt-1、Claude-Code-1、Azure-Gpt-4 等，都是 tryallapi 的**分组名**，不是官方产品线。同一模型 ID 不等于官方直连，也不等于官方服务等级承诺。价格、分组和可用性都会变，请以当天控制台和模型广场为准。官方 ChatGPT / Claude 消费端订阅、Free tier、Ultra / Pro 等门槛，只适用于官方界面，**不要套到 tryallapi 上**。

**先看 auto 调用链路，这是最容易误会的一点。** `gpt-6.2-astra` 详情页写的是「auto分组调用链路: Azure-Gpt-4 → Azure-Gpt-5」。按官方 Standard 短上下文标价计算，Azure-Gpt-4 约为 **0.968 倍**（输入 $7.7440，接近官方 $8），Azure-Gpt-5 约为 **1.32 倍**（输入 $10.5600，已经高于官方）。页面没有写 auto 会转到最便宜的 Codex-Gpt-1。低价只在你选中对应分组、并且该分组当天实际可打通时才可能生效；走 auto，有可能落到接近官方、甚至高于官方的 Azure 分组。本文不推测 auto 的其他内部规则。本次没有打开 `gpt-6.2-sol` 的详情页，所以不臆造 Sol 的 auto 链路；它当天的 `enable_groups` 与 Astra 相同，同样不能默认会打到 Codex-Gpt-1。

**再看阶梯倍率。** 左侧卡片给出的是单一的美元 / 1M 单价，对应 1x 基价，不能把它理解成「所有用量都按 0.08 倍官方价」。Astra 详情页和当日接口里的 `step_ratios` 一致：输入 Token 在 `[0, 272,000]` 时，非思考输入 / 输出倍率都是 1x；在 `(272,000, 1,000,000]` 时，非思考输入为 2x、非思考输出为 1.5x；输出 Token 数「不限」。接口里缓存倍率也是先 1x、后 2x。思考列在页面上是「-」，接口对应的思考倍率为 0，本文**不编造思考价**。这个 272K 分界与官方长上下文规则一致，但 tryallapi 是在自己的分组基价上再乘这些倍率。
